# 🐾 Desktop Pet — Claude Code / ZCode 会话状态桌面宠物

一只常驻桌面的小宠物，实时检测 **Claude Code** 和 **ZCode**（终端或 VS Code 里跑的都行）有没有在干活。

更多截图与功能讲解见 [项目介绍.md](项目介绍.md)。

**只有两种形态，完成是一种「事件消息」而不是持续状态：**

| 形态 | 宠物表现 | 含义 |
| --- | --- | --- |
| 🐕 工作中 | 快速蹦跳、点头、两只前爪交替敲、尾巴快摇、耳朵抽动、冒汗 | 任一来源有回合正在进行 |
| 😴 空闲 | 闭眼呼吸、慢慢张望、尾巴慢摇、Zzz | 当前没有进行中的回合 |

形象为**现成 SVG 动画**（SMIL，来自用户提供的素材，位于 `renderer/`）：
- 工作中 → `cat-typing.svg`（黑猫敲紫色笔记本）
- 空闲 → `black-cat.svg`（黑猫，自带动画）
- 舞台加柔白光晕保证深色桌面上黑猫可辨认；完成时跳三下 + 飘爱心（`#hearts`）；
  全部切换由 `#app` 的 `st-working` / `st-idle` 类驱动。

底部**状态栏**只在有会话工作时出现：显示工作中来源的 tag 和会话数量
（如 `● Claude ×1`、`● ZCode ×2`），全部空闲时隐藏。
宠物**右上角**常驻状态角标：空闲（灰点「空闲」）/ 工作中（橙色呼吸点
「工作中 · Claude ×1 · ZCode ×2」，**合并显示各 agent 会话数**，不再另设底部 tag）。
状态角标正下方还有**工作用时角标**（仅工作中显示）：「AI thinking」三点动画
+ `mm:ss`（满一小时 `h:mm:ss`），走表按用时整秒边界每秒准时跳一格；
一个任务里来回多个回合只累计「正在工作」的时间，回合间空闲不计时。
**空闲超过 1 分钟再开工视为新任务，用时清零重计**（连续回合间隔很短则继续累计）。
用时角标正下方是**工作消耗角标**（同为胶囊按钮，仅工作中显示）：本次任务累计的
**Token 消耗量**（纯 CSS **均衡柱**动态图标，三条错峰起伏传达"消耗在涨"，与用时角标
的三点同一套动效语言；数字 ≥1 万显示 `x.x万`；口径为**输入+输出总消耗**
含缓存读，与套餐额度扣减一致）。数据走**独立快速通道**：主进程每 400ms 增量扫描
本机日志（与 2s 的状态检测解耦），扫到新增立即推送渲染层——ZCode 取 rollout 每条
请求的 `usage.totalTokens`，Claude Code 取会话记录的 `message.usage` 四类 token
求和（子代理消耗也计入）。数字带**持续滚动动画**：rAF 平滑逼近目标，目标间隙按
最近增速小幅外推（窗口 1.2s，超出即停帧等新数据）；显示值**只涨不跌**——外推
一旦冲过真实值就原地暂停等它追上，决不回退。新任务清零由主进程显式下发
（`tokens` 事件带 `reset` 标记，与用时角标同一时刻归零），随用时角标一起显隐。
开工/互动气泡与完成气泡**同属一个堆叠流**（气泡是第一项，永远贴着猫头），
彼此排队不重叠：猫在屏幕下半时贴头顶向上堆叠，猫在屏幕上半时贴下方
往下堆叠（方向自适应），与右上角标也保持间距。

**任务完成时**（「整个任务」完成的判定见下），在**统一的位置**播报「什么任务完成了」：
- **完成气泡卡片**（白底黑字扁平风，可多个同时存在）：标题「ZCode 任务已完成」+ 副行「文件夹图标 + 项目名 · 秒表图标 + 用时 · 柱状图图标 + Token 消耗 · 完成时刻」；图标为内联矢量（来源 iconfont.cn，见 `renderer/icons.js`），界面不使用 emoji
  - 气泡只显示**最后一级项目文件夹名**，不显示完整路径
  - 时间显示在气泡上；默认 **5 分钟自动关闭**（`bubbleAutoCloseMs` 可配，0 = 不自动关），点 **×** 可手动关
  - 完成气泡（含开工气泡）永远**贴着猫头向上堆叠**（新气泡贴猫），不遮挡宠物
- **历史记录**：右键菜单 →「完成历史」打开面板，可翻看/清空最近 50 条（历史里保留**完整路径**）
  - 每条记录带**完成时刻**（当天显示时分，跨天记录带月-日）、**任务用时**（秒表图标，与工作时走表的累计口径一致）和本次任务的 **Token 消耗**（柱状图图标）
  - 面板是贴在猫**四角之一**的小卡片，不盖猫：猫在屏幕下半部 → 猫头**左上/右上**；上半部 → 猫脚**左下/右下**；左右贴边朝屏幕中间一侧靠
  - 面板打开时窗口向对应方向**临时扩高**（猫的位置不动），关闭后收回；空间不足会自动换向/限高
- 系统通知 + 提示音各播一次

**状态栏**：空闲时完全不显示；工作中显示工作中来源的 tag 和会话数量，如
`● Claude ×1`、`● ZCode ×2`（橙色呼吸点）。

**「整个任务完成」的定义**：不是每个回合结束就播报（那样对话过程会不停打扰），
而是回合结束后静默 `sessionEndGraceMs`（默认 3 分钟）期间**没有新回合**，
才判定整个任务完成并播报一次；期间你继续对话则自动撤销判定。

宠物可拖拽、可点击（随机蹦出 **500 条语录**，见 `renderer/click-lines.js`：约 1/10
是动态词，会填入**当前时间/星期/时段**；主进程联网取到天气（wttr.in，每 2h 刷新）
后还会出现**天气**语录，浏览器支持电量接口时有**电量**语录——取不到就自动只用固定语录，
连续点击不会重复同一句）。宠物**左上角**有 **Token 用量角标**（与右上角状态角标
对称）：显示最接近上限的配额百分比（≥80% 变红），点击打开**用量详情**；
右键**功能菜单**（与历史面板同款白卡片样式，条目带内联图标，提示音/置顶带橙色
勾选态）：开关提示音/置顶、完成历史、**参数设置**、**Token 厂家列表**、
打开程序目录、查看当前检测状态（气泡显示各来源实时状态）、退出。

**Token 用量**按厂家查询模型用量/余额，支持多家并存，`usage.js` 的 `PROVIDERS`
注册表即插即用：

| 厂家 | 数据 | Key 来源 |
| --- | --- | --- |
| GLM · 智谱 | 配额窗口（5h/周，≥80% 红）+ 今日/近 30 天用量 + 分模型明细 | 普通API Key |
| MiniMax / DeepSeek / Kimi · 月之暗面 / 硅基流动 | 账户余额 | 普通API Key |
| OpenAI / Anthropic | 今日/近 30 天 token 用量 | **组织管理员 Key** |
| 阿里云（百炼）/ 腾讯云（混元） | 云账户余额（BSS / 费用中心 API，本地完成签名） | **AccessKey / SecretId 密钥对**（建议只读子账号） |

> 火山方舟暂未接入：管控面/账务接口无公开稳定的免签 REST（需 AK/SK 四步签名且不对外承诺稳定），暂缺。

面板详情页（角标点击打开）是**聚合视图**（各已启用厂家的数据纵向堆叠）；详情页的
「厂家列表」或右键菜单「**Token 厂家列表**」进入**厂家列表**：每行一个**开关**，
控制该厂家是否显示在详情页，点厂家名（未配置时）进配置表单填 Key。查询地址内置
默认不用填；环境变量
`GLM_API_KEY` / `MINIMAX_API_KEY` / `DEEPSEEK_API_KEY` / `MOONSHOT_API_KEY` /
`SILICONFLOW_API_KEY` / `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`，云账号为
`ALIYUN_ACCESS_KEY_ID` + `ALIYUN_ACCESS_KEY_SECRET` /
`TENCENT_SECRET_ID` + `TENCENT_SECRET_KEY`，优先级高于面板保存的值（另可用
`GLM_BASE_URL` 等覆盖接入点）。Key 只存本机 `userData/usage-config.json`，
源码与日志不落明文，界面只回显掩码；查询结果 60 秒缓存，「刷新」强制重拉。

**参数设置面板**（与历史面板同款小卡片）是 `config.json` 的可视化入口：
数值参数按预设档位 `‹ ›` 步进（完成宽限、气泡自动关为**秒级档位**：10 秒起），
也可**点击数值直接输入自定义时长**——单位秒，认 `90` / `90秒` / `3分` 这类写法，
Enter 提交、Esc 取消（气泡自动关可输 0 = 不自动关，其余最小 5 秒）；
监控 Claude/ZCode 为拨动开关，「默认」一键恢复默认值。
**改动实时生效**（宽限期/轮询间隔热应用，无需重启）并写回 `config.json`。

## 运行

```bash
npm install   # 已装好可跳过
npm start     # 或直接双击 start.bat（直接拉起项目内 electron，无残留控制台窗口）
```

桌面快捷方式 `桌面宠物.lnk` 与 `start.bat` 等效（快捷方式图标为 `cat.ico`，取自动画中的一帧）；应用有单实例锁，重复启动只会让现有窗口聚焦。

## 检测原理（无侵入，只读文件）

- **ZCode**：读 `~/.zcode/cli/log/zcode-*.jsonl` 的生命周期事件
  （`turn.phase.started/completed`、`model.request.*`、`tool.call.*`）。
  事件按 `sessionId` 分组，某会话自己的最新 `started` 晚于自身最新 `completed`
  ⇒ 该会话**工作中**（工具跑很久也不会误判；多会话并行互不干扰）；
  否则即空闲。日志解析不到时降级用 `~/.zcode/cli/rollout/model-io-sess_*.jsonl` 的 mtime 短窗口兜底。
- **Claude Code**：扫 `~/.claude/projects/<编码目录>/<sessionId>.jsonl`，
  解析文件尾部记录判断回合状态（**秒级感知，不看 mtime 冷却**）：
  - 末条主线记录是 `assistant` 且带 `tool_use` ⇒ **工作中**（长命令几分钟也不会误判）；
  - 末条主线记录是纯文本 `assistant` ⇒ **回合结束，立即空闲**（并触发完成事件）；
  - 末条是 `user`（工具结果/新输入）⇒ 工作中；子代理（isSidechain）行自动跳过。
  尾部解析失败时退化为 mtime 启发式。项目名会反解成真实路径（连字符歧义用「路径存在性」消歧）。

## 配置（config.json）

除 `sound` 外的参数都可在**右键菜单 →「参数设置」**面板里直接调整（实时生效并写回本文件）：

```jsonc
{
  "pollIntervalMs": 2000,        // 轮询间隔
  "workingWindowMs": 30000,      // 尾部解析失败时的 mtime 退化窗口
  "claudeStaleWorkingMs": 900000,   // tool_use 挂起最多保持工作中的时长（防进程崩溃卡死）
  "zcodeInFlightMaxAgeMs": 600000,  // 回合进行中判定的事件最大年龄
  "sessionEndGraceMs": 180000,   // 回合结束后静默多久才判定"整个任务完成"（期间有新回合则取消）
  "bubbleAutoCloseMs": 300000,   // 完成气泡自动关闭毫秒数（0 = 不自动关，手动 ×）
  "watch": { "claude": true, "zcode": true },
  "sound": true                  // 完成提示音（右键菜单也会写回这个值）
}
```

## 已知局限

- ZCode 回合被用户中途打断且日志缺 `completed` 事件时，最多多显示 10 分钟工作中的工作状态，有新事件立即恢复；Claude 同理由 `claudeStaleWorkingMs` 保护。
- 完成消息里的「任务名」：Claude Code 用项目名；ZCode 用工作区名（取自**当前会话** rollout 首行 system prompt 里的 `Primary working directory`，会话切换自动跟随；`bot-state.v3.json` 仅作回退）。ZCode 的会话标题存在任务索引 sqlite 中（需实验性 flag 读取），暂未接入。
- 会话数是**精确的并行会话数**：ZCode 按日志事件里的 `sessionId` 分组，数"回合进行中"
  （该会话最新 `started` 晚于自身最新 `completed`）的会话，刚结束的会话立即退出计数、
  长工具执行中的会话也不会漏；Claude 按各会话文件尾部的回合状态统计，不再只看最新的
  一个文件。会话被强杀/崩溃时其"进行中"标记最多残留 `zcodeInFlightMaxAgeMs` /
  `claudeStaleWorkingMs`（有新事件立即恢复）。

## 结构

```
main.js        Electron 主进程：透明置顶窗、拖拽、托盘、通知、右键菜单状态/动作桥
monitor.js     检测核心 + 本次任务 Token 消耗的增量扫描（可独立 node monitor.js --once 运行）
usage.js       Token 用量查询（provider 抽象：glm=智谱 Coding Plan，可扩展）
icon.js        纯代码生成托盘 PNG（无二进制资源）
preload.js     contextBridge 安全桥
renderer/      宠物 UI（SVG + CSS 动画 + WebAudio 提示音 + 统一事件栏）
```

## 接入新来源

在 `monitor.js` 里加一个 `xxxStateFromData()` 纯函数 + 一个扫描函数，状态只返回
`working / idle`，挂进 `SessionMonitor.snapshot()` 即可——完成播报、状态栏、
事件栏全部自动复用，无需改 UI。
